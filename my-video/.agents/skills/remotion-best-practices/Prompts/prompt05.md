🏀 Video #3: Basketball-Specific Landing Page Video

**(55–60 seconds)**

**Purpose:** Landing page video that positions Skedence as the operating system for basketball training businesses

**Tone:**  
Professional. Direct. Confident. Basketball-focused.  
This speaks to serious basketball trainers who want to scale.

---

## 🎬 STRUCTURE

### SCENE 1 — The Hook (0–5s)

**Visual:** Dark background with subtle basketball court lines  
**Text on screen:**

```
"Running a basketball training business?"
```

Pause 1 second.

```
"You need an operating system"
```

Let it land.

---

### SCENE 2 — The Reality (5–18s)

**Visual:** Floating text messages in background (larger size, glassmorph style)

Messages appear one by one:
- "Can we reschedule tomorrow?"
- "Which package did I buy?"
- "Venmo sent for 3 sessions"
- "Available for 6am workouts?"

**Then text overlay:**

```
"With 5 athletes, you can manage this"
```

Pause.

```
"With 15+, you're losing money"
```

Direct. No exaggeration.

---

### SCENE 3 — The Operating System (18–38s)

**Visual:** Dashboard screenshots with smooth transitions

**Shot 1:** Scheduling dashboard  
**Text:** "One schedule for all your athletes"

**Shot 2:** Packages page  
**Text:** "Sell training packages upfront"

**Shot 3:** Revenue dashboard  
**Text:** "Track every dollar automatically"

**Shot 4:** Mobile apps side-by-side  
**Text:** "Athletes book. You get paid. Everyone stays synced"

Clean. Professional. Let the platform speak.

---

### SCENE 4 — The Math (38–52s)

**Visual:** Dark background with numbers

**Text animates in:**

```
"20 athletes"
"10 sessions/month average"
"$90 per session"
```

**Revenue number builds up:**

```
"$18,000/month"
```

Pause.

**Final text:**

```
"That's not a side hustle"
"That's a business"
```

This hits identity. This is the shift.

---

### SCENE 5 — The Close (52–60s)

**Visual:** Return to dashboard or logo with orange glow

**Text:**

```
"Skedence"
```

**Tagline:**

```
"The operating system for basketball training"
```

Simple. Memorable. Clear positioning.

---

## 🎨 DESIGN NOTES

- **Colors:** Dark background (#0f1115), Orange accent (#ff6b35), White text
- **Basketball elements:** Subtle court lines in backgrounds, hardwood texture overlays
- **Typography:** Bold, clean, professional (Inter font)
- **Pacing:** Faster than volleyball video - basketball energy
- **Music:** Same background.mp3 at 30% volume
- **No periods:** Keep copy punchy and direct

---

## 🎯 KEY DIFFERENTIATORS FROM VOLLEYBALL

1. **Positioning:** "Operating system" language vs just "built for training"
2. **Energy:** Slightly faster pacing to match basketball culture
3. **Numbers:** Higher revenue math (20 athletes vs 12)
4. **Identity:** "That's not a side hustle, that's a business" - aspirational
5. **Athletes:** References to scales (5 → 15+) to show growth path
