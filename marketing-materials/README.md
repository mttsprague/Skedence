## How to Use

### Method 1: Print to PDF (Recommended)

1. Open any HTML file in Chrome or Safari
2. Press `Cmd + P` (Mac) or `Ctrl + P` (Windows)
3. Select "Save as PDF" as destination
4. **Important Print Settings:**
   - Margins: None or Minimal
   - Background graphics: ✓ Enabled (critical for colors)
   - Scale: 100%
5. Save the PDF

### Method 2: Export from Browser

1. Open HTML file in browser
2. Right-click > Print
3. Choose PDF as printer
4. Enable background graphics
5. Save

### Method 3: Use Design Tool

1. Open HTML in browser
2. Take full-page screenshot (Chrome DevTools can do this)
3. Import into Figma/Canva for further editing
4. Export as PDF

## Print Settings (Important!)

To ensure colors and gradients print correctly:

- ✓ Enable "Background graphics"
- ✓ Enable "Print backgrounds"
- ✓ Use "Actual size" (100% scale)
- ✓ Margins: None
- ✓ Color: Color (not black & white)

## Customization

All files are standard HTML/CSS. To customize:

1. Open file in any text editor
2. Search for text you want to change
3. Edit content directly
4. Save and reopen in browser
5. Print to PDF
