## 🎨 How to Convert HTML to PDF

### Method 1: Browser (Best Quality)
1. Open the HTML file in Chrome, Safari, or Firefox
2. Press **Cmd+P** (Mac) or **Ctrl+P** (Windows)
3. Select "Save as PDF" as printer
4. Adjust settings:
   - **Layout:** Portrait
   - **Margins:** None or Minimum
   - **Background graphics:** ON (important!)
5. Save the PDF

### Method 2: Online Converter
- Use services like:
  - CloudConvert
  - HTML to PDF converter websites
  - Zamzar

### Method 3: Professional Tools
- Adobe Acrobat
- Microsoft Word (paste HTML)
- Design tools (Figma, Canva - recreate design)

## 📧 Email Campaigns - How to Use

### Campaign Strategy

**Week 1 - Introduction**
- Send: `email-campaign-1-introduction.html`
- Subject: "Transform Your Training Business"
- Goal: Introduce Skedence, get response

**Week 2 - Features Deep Dive** (if no response)
- Send: `email-campaign-2-features.html`
- Subject: "5 Features That Will Save You 10+ Hours/Week"
- Goal: Show specific value, book demo

**Week 3 - Case Study/Offer** (create custom)
- Share success story or limited-time offer
- Goal: Create urgency

**Week 4 - Final Touch** (if still no response)
- Brief check-in with one-page overview attached
- Goal: Stay top-of-mind

### Personalization Tips

Before sending, customize:
1. **Greeting** - Use their actual name
2. **Opening** - Reference how you found them or mutual connection
3. **Pain points** - Adjust to their specific situation
4. **Closing** - Add personal signature

### Sending Methods

**Option 1: Copy HTML into email client**
- Works in: Gmail, Outlook (web), Apple Mail
- Displays as designed with colors and layout

**Option 2: Send as attachment**
- Save as PDF first
- Good for cold outreach where HTML might be blocked

**Option 3: Host online and share link**
- Upload HTML to web server
- Share clean URL
- Track clicks if using link shortener

## 🎯 Customization Tips

### Adding Screenshots
The sales deck has placeholder boxes marked `[Screenshot - Description]`. To add real screenshots:

1. Take screenshots of your admin portal:
   - Dashboard overview
   - Client profile page
   - Calendar view
   - Reports/analytics
   - Package management

2. Replace placeholder divs with images:
```html
<div class="screenshot">
  <img src="screenshot-dashboard.png" style="width: 100%; border-radius: 12px;" alt="Dashboard">
</div>
```

### Updating Pricing
If pricing changes, update in:
- `sales-deck.html` (pricing page)
- `one-page-overview.html` (pricing box)
- Both email templates (pricing mentions)

### Adding Your Branding
