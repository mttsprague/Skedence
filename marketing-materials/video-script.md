## PRODUCTION NOTES

### Visual Style:
- Clean, modern aesthetic matching the brand
- Smooth transitions between scenes
- Use gradient colors (purple to blue: #667eea to #764ba2)
- Minimize text on screen - let visuals speak
- Use cursor highlights for screen recordings

### Music:
- Upbeat, professional background music
- Not too energetic, maintains focus
- Volume fades during narration

### Screen Recording Tips:
- Record at 1920x1080 or higher
- Hide unnecessary UI elements
- Use smooth, deliberate mouse movements
- Zoom in on important interactions
- Pre-load all pages to avoid loading states

### Voiceover:
- Professional but friendly tone
- Moderate pace - not rushed
- Clear enunciation
- Slightly enthusiastic but authentic

### File Formats for Export:
- MP4 (H.264)
- 1920x1080 resolution
- 30fps
- Optimized for web (under 50MB if possible)
- Include subtitles/captions file (SRT)
