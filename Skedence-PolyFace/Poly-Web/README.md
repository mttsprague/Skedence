# Polyface Volleyball Academy - Website Mockups

Three modern website designs for Polyface Volleyball Academy (polyfacevolleyballacademy.com).

## Color Scheme
- Navy (POLY): `#14244E`
- Teal (FACE): `#4DA6B0`
- Green: `#6EBC45`
- Orange: `#E89D32`
- Light Blue: `#86C5D9`

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open browser to `http://localhost:3000`

## Design Routes

- **Design 1** (Hero Video with Modern Cards): `/` or `http://localhost:3000`
- **Design 2** (Split Screen Bold): `/design2` or `http://localhost:3000/design2`
- **Design 3** (Minimalist Gradient): `/design3` or `http://localhost:3000/design3`

## Taking Screenshots

1. Run `npm run dev`
2. Open each route in your browser
3. Use browser's full-page screenshot feature or screenshot tool
4. Recommended viewport: 1920x1080 for desktop screenshots

## Design Features

### Design 1
- Hero section with video background placeholder
- Modern card-based program displays
- Stats section with gradient text
- Bold CTAs with orange accents

### Design 2
- Split-screen hero layout
- Featured pricing card (middle card elevated)
- Dark navy theme throughout
- Gradient feature strips

### Design 3
- Clean, minimalist aesthetic
- Subtle gradient blobs as background
- Floating card elements
- Emphasis on white space and typography

## Build for Production

```bash
npm run build
```

This creates a static export in the `/out` directory.
